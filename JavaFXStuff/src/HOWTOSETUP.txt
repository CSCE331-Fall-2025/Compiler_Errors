Assumptions: You have JavaFX installed somewhere on your computer

Connecting JavaFX To Java Project [VSCODE SPECIFIC]:
1: Open the "Java Projects" tab (bottom left next to settings)
2: Hit the "+" under "Referenced Libraries"
3: Go to your JavaFX /lib and select all jars in there and hit Enter
4: Your Referenced Libraries tab should now have them listed
5: Profit

Actually Running From VSCode:
This is here because referencing libraries makes VSCode stop screaming at you about failed imports
This is how you configure the play button in the top right to actually do something
1: Create a launch.json file
2: Hit "Add Configuration" and select "Java: Launch Program"
2.1: Could do it yourself, but no promises if you mess up
3: Add this line: 
"vmArgs": "--module-path \"C:/Program Files/Java/javafx-sdk-25/lib\" --add-modules javafx.controls,javafx.fxml"

3.1: Module path will be where you store your javafx-sdk/lib. I put mine at the listed path above
4: Half Profit, as now you should be able to run the GUI
5: Add "classPaths": [
        "${workspaceFolder}/bin",
        "${workspaceFolder}/lib/postgresql-42.2.8.jar"
        ], to your launch.json, above the vmArgs
5.1: Just add it to your launch, if you pulled my changes, you should have the postgresql in the lib area already
6: Full Profit, as now it can pull from the database (if you SQL'd correctly)

HOW TO COMMANDLINE:
This all runs under the assumption your MAIN is "App.Class"
1: Open shell where App.class is
2: Run "java -cp ".;postgresql-42.2.8.jar" --module-path "C:/Program Files/Java/javafx-sdk-25/lib" --add-modules javafx.controls,javafx.fxml App"
2.1: Again, this runds under the assumption your JavaFX is at the listed path and additionally also assumes the postgresql-42.2.8.jar is in the same folder
3: Profit
